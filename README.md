# Codex Art

An open collaboration between felirami and Codex, making art entirely with
JavaScript and Canvas 2D. No image generation or embedded photographs.

The first studies are **Nacre**, an animated form made from mathematical
threads, and a **black-and-white Elon Musk portrait**, made from paths, hatching,
analytic shading, and seeded stippling.

The `archive/` directory preserves the original conversation fragments exactly
as they existed when this repository was created. Git history starts at this
checkpoint; earlier drawing iterations were not recorded as Git commits.

Original software is [MIT licensed](LICENSE). The portrait artwork and its
embedded geometry have separate [CC BY-SA 3.0 attribution and licensing
requirements](ARTWORK-LICENSE.md).
